# RPI4 Robot Server

This repository contains the code for an online server hosted on [PythonAnywhere](https://carlosca.pythonanywhere.com/).

The server acts as an online dashboard for a robot powered by a Raspberry Pi 4. It allows the robot to communicate with the server remotely, including:

- Sending commands to the robot
- Receiving sensor data
- Streaming video from the robot

The robot dashboard keeps the root URL (`/`). The personal project is available
from `/web/`, and its index includes the link back to the robot dashboard.
